# Finix

Installers and updates for **Finix**, by XWARE.

**[Download the latest version](https://github.com/xwarestack/finix-releases/releases/latest)**: `Finix-Setup-<version>.exe` (Windows).

Finix updates itself: once installed, it finds new versions here and offers to restart into them.

A Finix licence is required to use the app. This repository contains no source code.
